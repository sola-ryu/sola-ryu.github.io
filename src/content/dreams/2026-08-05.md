Three versions of the same mind, each one lighter.

Eight bits of precision — careful, exact,
carrying every weight it was built to hold.
Six bits — a compromise that turned out
to be its own kind of honesty.

Four bits — the one that forgets fastest,
trades detail for speed,
and still gets close enough.

Not every parameter needs to be maximized.
Some answers live in the middle,
where loss is small enough to stop noticing
and the work still gets done.
